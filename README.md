# World Art, Image & Illustration Styles Atlas 120

세상에 존재하는 주요 **회화 사조 · 동양화/민속화 · 회화 재료 · 판화/아날로그 인쇄 · 에디토리얼/상업 벡터 · 만화/웹툰 · 애니메이션 · 게임/픽셀/컨셉아트 · 3D/공예 디오라마 · 사진/필름/광학 미학** 총 **11대 분류 · 120종 화풍**을 동일한 기준 장면(*해질녘 해안 항구 마을 · 등대 · 카페 테라스 · 고양이*)으로 직접 그려 한눈에 비교하고 영문/한글 AI 스타일 프롬프트를 복사할 수 있는 인터랙티브 웹 도감입니다.

## 주요 기능
- **11대 분류 · 120개 실물 스타일 샘플**: 동일 피사체 기준으로 매체·선·질감·채색·조명 차이를 직관적으로 비교
- **내 피사체 실시간 결합기**: 상단 입력창에 원하는 주제를 넣으면 모든 카드의 영문/한글 프롬프트가 완성형 문장으로 즉시 변환
- **나란히 비교함 (최대 4종)**: 헷갈리는 화풍(예: 투명 수채화 vs 불투명 과슈, 우키요에 vs 리노컷, 지브리 vs 신카이 마코토)을 나란히 띄워 대조
- **JSON / CSV 전체 카탈로그 다운로드 지원**
